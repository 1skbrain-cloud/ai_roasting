### 클라우드 세션 화면 구성

 ![Claude 앱 코드 탭 화면. 위에 환경 이름 Default, 제안 프롬프트 세 개, GitHub 저장소 칩, 입력창, 아래에 모델과 권한 모드](https://bizroasting.com/assets/img/ui/claude_app_code_site.jpeg)


맨 위 Default

처음 만들 때 붙는 환경 이름입니다. 저장소마다 다른 환경을 만들면 여기서 선택합니다.


GitHub 저장소

작업할 저장소를 선택합니다. 목록이 비어 있으면 GitHub가 연결되지 않은 상태입니다.


입력창

작업을 문장으로 입력합니다. 파일이나 함수 이름을 명시하면 결과가 개선됩니다.


아래 줄

왼쪽은 사용할 모델, 오른쪽은 권한 모드입니다. 화면에서는 Opus 5와 수정 수락이 선택되어 있습니다.

클라우드 세션이 안 될 때

- GitHub 저장소가 없으면 시작할 수 없습니다. 클라우드 세션은 저장소를 복제해 작업하는 방식입니다. 없다면 GitHub에서 빈 저장소를 하나 먼저 만듭니다.

- 처음 한 번은 연결 절차가 필요합니다. claude.ai/code에 들어가 로그인하면 GitHub를 연결하라는 안내가 뜹니다. Claude GitHub 앱을 설치해 접근을 허용하고, 이어서 나오는 환경 만들기 화면은 기본값 그대로 만들면 됩니다.

- 저장소 목록이 비어 있다면 연결한 GitHub 계정이 그 저장소를 볼 수 있는지 확인합니다. 회사 계정이면 관리자가 막아 둔 경우도 있습니다.

- GitHub를 연결하지 않으려면 리모트 컨트롤을 사용합니다. 내 컴퓨터에서 실행되므로 GitHub가 필요 없습니다.

 알림 설정

리모트 컨트롤이 켜져 있으면 긴 작업이 끝나거나 결정이 필요할 때 스마트폰으로 알림이 옵니다. 프롬프트에 "테스트 끝나면 알려줘"처럼 명시해도 됩니다. 컴퓨터가 잠들었다가 깨어나면 세션은 다시 연결됩니다.

스마트폰에서 지원하지 않는 것

- 터미널 전용 명령은 사용할 수 없습니다. /plugin, /resume처럼 터미널에서만 실행되는 명령은 앱에서 동작하지 않습니다.

- 권한 모드는 세션에 따라 선택 범위가 다릅니다. 리모트 컨트롤은 수동·수정 수락·계획, 클라우드 세션은 수정 수락·계획·자동입니다. 터미널에만 있는 '권한 무시'는 앱에서 고를 수 없습니다.

- 코드 탭이 표시되지 않으면 요금제 문제입니다. 개인 계정은 요금제를 상향해야 하고, 회사 계정이면 관리자에게 이 기능을 열어 달라고 요청해야 합니다.

 권한 모드 네 가지

수동은 파일을 수정하거나 명령을 실행하기 전에 매번 확인합니다. 수정 수락은 파일 수정과 폴더 정리는 확인 없이 진행합니다. 계획은 먼저 읽고 방법을 제안한 뒤 승인을 기다립니다. 자동은 안전 점검을 백그라운드에서 수행하며 확인 없이 끝까지 진행합니다. 처음에는 수동이나 계획으로 설정하고, 익숙해지면 수정 수락으로 변경합니다.

Dispatch

## 스마트폰에서 지시하고 컴퓨터가 실행합니다

회의 시작 5분 전

어제 받은 견적서 세 개 열어서 업체명이랑 금액, 납기만 표로 정리해 둬.

오전 9:12 · 나

회의 진행 50분

표로 정리해서 바탕화면에 뒀습니다. 금액은 A사가 가장 낮고, 납기는 C사가 2주 빠릅니다.

오전 10:05 · Claude

 배정은 Claude가 합니다

코드를 수정하는 작업은 클로드 코드로, 문서와 자료를 다루는 작업은 코워크로 자동 배정됩니다. 과정은 생략되고 결과만 메시지로 전달됩니다. 표, 메모, 비교 자료 등입니다. 작업이 끝나거나 승인이 필요하면 알림이 옵니다.

### 설정 순서


양쪽 앱을 최신으로 업데이트합니다

컴퓨터에 Claude 데스크톱 앱, 스마트폰에 Claude 앱을 설치하고 같은 계정으로 로그인합니다. 두 기기 모두 인터넷에 연결돼 있어야 합니다.


내 컴퓨터에서 Dispatch를 켭니다

데스크톱 앱 왼쪽 메뉴에서 발송을 누르면 설정 카드가 나옵니다. 절전 모드 방지는 화면이 꺼져도 작업을 이어갈지, 모바일 알림은 완료 시 스마트폰으로 알릴지 정하는 항목입니다. 앱 버전에 따라 화면은 조금씩 다릅니다.


스마트폰에서 작업을 지시합니다

스마트폰의 Dispatch에 작업을 입력하면 컴퓨터가 처리합니다.

### 발송 화면 구성

데스크톱 앱의 발송이 Dispatch입니다. 오른쪽 설명을 누르거나 마우스를 올리면 화면의 해당 자리에 표시가 나타납니다.

이 화면에서 활성화할 항목은 둘입니다. 절전 모드 방지와 모바일 알림. 나머지 둘은 기본값으로 둡니다.


발송여는 자리

왼쪽 메뉴에서 누릅니다. 아직 베타 표시가 붙어 있습니다.


절전 모드 방지켜기

컴퓨터가 절전되어도 작업을 이어갑니다. 끄면 자리를 비운 동안 중단됩니다.


모바일 알림켜기

작업이 끝나거나 승인이 필요할 때 스마트폰으로 알립니다.


컴퓨터 사용필요할 때만

Claude가 화면을 직접 조작합니다. 연결 통로가 없는 프로그램에만 사용합니다.


코드 권한물어보기로

화면의 우회는 묻지 않고 진행하는 설정입니다. 익숙해지기 전에는 확인하는 쪽으로 설정합니다.


출력저장 폴더

Claude가 생성해 공유하는 파일이 저장됩니다.

사용 전 확인 사항

- Pro 또는 Max 요금제여야 합니다. Team과 Enterprise에서는 Dispatch를 쓸 수 없습니다.

- 컴퓨터가 깨어 있고 데스크톱 앱이 열려 있어야 합니다. 작업이 클라우드가 아니라 내 컴퓨터에서 실행되기 때문입니다. 컴퓨터를 꺼야 한다면 코드 탭의 클라우드 세션을 사용합니다.

- 화면을 직접 조작하는 기능은 미리보기 단계입니다. 연결 통로가 없는 프로그램을 다룰 때만 쓰고, Pro와 Max에서만 제공됩니다.

- 대화는 하나로 유지됩니다. Dispatch 안에서 별도 대화를 새로 만들 수는 없고, 작업이 한 대화에 누적됩니다.

코워크

## 코워크는 컴퓨터의 파일을 직접 열어 처리합니다

채팅은 답변을 제시하고 종료됩니다. 코워크는 데스크톱 앱이 내 컴퓨터의 파일을 직접 열어 정리하고, 결과물을 파일로 만들어 둡니다. 2026년 4월 9일 맥과 윈도우에 정식 제공됐습니다.

스마트폰의 코워크 메뉴는 컴퓨터에서 실행 중인 작업을 확인하는 화면입니다. 스마트폰에서 새로 시킬 때는 Dispatch를 씁니다.

 코워크와 클로드 코드 중 무엇을 고를 것인가

선택하지 않아도 됩니다. Dispatch에 맡기면 자료를 정리하는 작업은 코워크로, 코드를 수정하는 작업은 클로드 코드로 Claude가 배정합니다.

 노코드로 시작한다면

코워크와 클로드 코드는 둘 다 파일을 직접 다룹니다. 터미널 없이 시작하는 방법은 [바이브 코딩 101](https://bizroasting.com/vibe-coding-101.html)에 정리돼 있습니다.

실행 순서와 확인 사항

## 실행 순서

 1) 요금제부터 확인합니다

스마트폰 앱에서 설정을 열어 요금제를 봅니다. Pro나 Max는 Dispatch까지 사용할 수 있습니다. 무료나 Team, Enterprise는 Dispatch를 제외하고 채팅과 프로젝트부터 사용합니다.

 2) Pro·Max는 Dispatch를 설정합니다

컴퓨터에서 데스크톱 앱을 열고 [위의 설정 순서](https://bizroasting.com#sec-dispatch)를 그대로 따라 합니다. 설정을 마친 뒤 스마트폰으로 다음과 같이 지시합니다.

바탕화면에 있는 견적서 파일 세 개를 열어서, 업체명·금액·납기만 추출해 표 하나로 정리해 둬.

 3) 결과가 오면 컴퓨터에서 확인합니다

작업이 끝나면 스마트폰으로 알림이 옵니다. 승인을 요청하면 내용을 확인하고 누릅니다. 한 번 실행해 보면 나머지 메뉴도 파악됩니다.

### 선택 기준


컴퓨터를 꺼 둬야 하나요?

그렇다면 코드 탭의 클라우드 세션뿐입니다. 나머지 둘은 내 컴퓨터가 켜져 있어야 합니다.


코드를 수정하는 작업인가요?

맞으면 코드 탭, 아니면 Dispatch입니다. 판단이 어려우면 Dispatch에 맡겨 Claude가 배정하게 합니다.


Claude가 열 수 없는 프로그램인가요?

연결 통로가 없는 프로그램이라면 컴퓨터 사용을 켭니다. 화면을 직접 조작하는 방식이라 느리고 오류 가능성이 있으므로 마지막 선택지로 둡니다.

시작 전 확인 사항

- 내 컴퓨터에서 실행됩니다. Dispatch와 리모트 컨트롤은 실제로 내 파일을 읽고 고칩니다. 되돌리기 어려운 작업은 승인 알림을 확인하고 누릅니다.

- 회사 기기라면 정책을 먼저 확인합니다. 파일 접근과 화면 조작을 허용하는 설정이라 IT 정책에 저촉될 수 있습니다.

- 입력할 정보의 범위를 미리 정합니다. 판단 기준은 [AI와 안전하게 일하는 법](https://bizroasting.com/security-guide.html)에 다섯 가지로 정리돼 있습니다.

### 자주 묻는 질문

 Q. 무료 플랜에서도 Dispatch를 쓸 수 있나요?

아닙니다. Pro 또는 Max 요금제가 필요합니다. Team과 Enterprise 계정에서도 제공되지 않습니다.

 Q. 컴퓨터를 꺼 두고 스마트폰으로만 일을 시킬 수 있나요?

코드 탭의 클라우드 세션은 가능합니다. Dispatch와 리모트 컨트롤은 내 컴퓨터에서 실행되므로 컴퓨터가 켜져 있어야 합니다.

 Q. 정해진 시각에 자동으로 실행하고 싶습니다.

스마트폰에서 지시하는 방식이 아니라 예약 실행입니다. [Routines 예약 실행](https://bizroasting.com/routines.html)과 [헤르메스 에이전트](https://bizroasting.com/agents-tools.html#sec2)에 있습니다.

 Q. 앱에서 아이패드도 되나요?

가능합니다. 아이패드에는 같은 iOS 앱을 설치합니다.
