- 프롬프트를 그대로 복사하지 말고, 내 상황에 맞게 제품명·색상·기능을 바꿔보세요

- ★ 표시 스킬은 그 과제에서 처음 배우는 핵심 개념입니다. 특히 집중해서 실습하세요

 01

스탑워치 만들기 · 디자인 변경

 ★☆☆☆☆ 결과물: 피카소풍 얼굴이 배경에 깔린 스탑워치 약 15분

 ▼

이 과제로 배우는 것

요청 한 줄로 앱을 만들고, 다음 요청 한 줄로 이미 만든 파일을 고칩니다. AI가 내 컴퓨터의 파일을 직접 만들고 고친다는 점을 확인합니다.

1단계 · 만들기

스탑워치 웹페이지를 만들어줘.

2단계 · 디자인 변경

피카소가 그린 얼굴이 시계 배경으로 나오도록 디자인 변경해줘.

완료 기준

- 브라우저에서 스탑워치가 열리고 시작, 정지, 초기화가 모두 작동합니다.

- 시계 뒤에 피카소풍 얼굴이 보이고, 숫자가 그 위에서 또렷하게 읽힙니다.

  막히면 · 자주 나오는 문제 3가지

파일을 만들었다는데 화면이 보이지 않습니다

방금 만든 스탑워치 파일을 브라우저에서 열어줘.

디자인을 바꾸라고 했더니 새 파일이 생겼습니다

새로 만들지 말고 처음 만든 스탑워치 파일을 고쳐줘.

배경 그림이 깨지거나 빈칸으로 나옵니다

외부 이미지 주소를 쓰지 말고, 피카소풍 얼굴을 SVG로 직접 그려서 넣어줘.

 02

멀티 페르소나로 개선하기

 ★★☆☆☆ 결과물: 다섯 역할이 채점하고 고친 스탑워치와 점수 변화표 약 20분

 ▼

프롬프트

방금 만든 스탑워치 화면을 아래 다섯 명이 함께 개선해줘. 각자 자기 역할의 기준으로만 보고, 다른 사람과 같은 지적은 하지 마. 블랙 · UI/UX 디자이너 (수행자) 나머지 네 명의 지적을 모아 화면을 직접 고친다. 무엇을 왜 바꿨는지 한 줄씩 남긴다. 레드 · QA 엔지니어 (이성 비평가) 기능이 맞게 작동하는지 본다. 시간 오차, 버튼을 연달아 누를 때, 랩 기록 순서, 새로고침했을 때. 실버 · 육상 경기 계측원 (분야 전문가) 실제 계측 장비 기준으로 본다. 1/100초 표시, 랩과 구간 구분, 기록 표기 방식, 빠진 기능. 블루 · 사용성 연구원 (공감 비평가) 처음 쓰는 사람이 어디서 멈칫하는지 본다. 버튼 이름, 지금 상태가 보이는지, 글자 대비, 누르기 쉬운 크기. 골드 · 트랙 코치 (실제 사용자) 운동장에서 휴대폰 한 손으로 선수 랩을 잰다. 햇빛 아래서 3초 안에 쓸 수 있는지 본다. 진행 순서 1. 블랙을 뺀 네 명이 각자 10점 만점 점수, 근거, 고칠 것 3개를 낸다. 2. 블랙이 지적을 중요한 순서로 정리해 직접 고친다. 3. 네 명이 다시 채점한다. 네 명 평균이 9.5점을 넘을 때까지 반복한다. 최대 3번. 4. 마지막에 역할별 점수가 처음과 끝에 어떻게 바뀌었는지 표로 보여줘.

기대 효과

답변 하나로 끝내지 않고 다섯 관점에서 검토한 뒤 스스로 고칩니다. 혼자 볼 때는 지나쳤던 문제가 드러납니다.

 03

GitHub 업로드

 ★★★☆☆ 결과물: 내 아이디 주소로 열리는 웹사이트 약 30분 GitHub

 ▼

진행 순서

1. GitHub.com 아이디 생성 (크롬에서 로그인해 둔 상태로 진행) 2. New Repository 생성 3. AI에게 GitHub 로그인 요청 "GitHub CLI(gh)를 설치하고 gh auth login을 웹 브라우저 방식으로 실행해줘" 4. 화면에 뜬 여덟 자리 코드(XXXX-XXXX)를 복사 → 크롬이 열리면 코드를 붙여넣고 Authorize github 클릭 : 토큰이나 비밀번호를 AI에게 직접 줄 필요가 없음 5. AI에게 "이 폴더를 방금 만든 Repository에 올려줘(Push)"라고 요청 6. GitHub.com에서 해당 Repo 클릭 → Settings → Pages → Branch에서 main, /root 선택하고 Save 7. 아이디.github.io/Repository명 으로 웹사이트로 접근

기대 효과

git init부터 commit, push, Pages 배포까지 자연어 한 줄로 끝냅니다. 내 작품이 인터넷에 공개되는 순간을 경험합니다.

1단계 · 탐색적 데이터 분석으로 시사점 5개 뽑기

 06

엑셀 실적 데이터로 온톨로지와 지식 그래프 만들기

 ★★★★☆ 결과물: 온톨로지와 지식 그래프를 담은 HTML 한 장 약 40분

 ▼

이 실습의 순서

엑셀 파일 속 대상(매장, 메뉴, 공급사, 배달 플랫폼, 사건)과 그 관계를 AI에게 정리하게 합니다. 대상과 관계의 규칙이 온톨로지, 그 규칙대로 실제 대상을 이은 그림이 지식 그래프입니다. 1단계에서 온톨로지를 HTML로 저장하고, 2단계에서 같은 HTML에 지식 그래프를 더합니다. 파일에는 함정이 두 개 있습니다. 시트마다 같은 매장이 다른 이름으로 적혀 있고, 매출 항목에 상품이 아닌 배달비가 섞여 있습니다. AI가 이 함정을 알아채는지가 이 실습의 핵심입니다.

 [ 샘플 엑셀 파일 다운로드](https://bizroasting.com/assets/claudecode/06_dashboard/데이터/%ED%94%BC%EC%9E%90%20%EB%A7%A4%EC%9E%A5%EB%B3%84%20%EC%8B%A4%EC%A0%81%20%EB%8D%B0%EC%9D%B4%ED%84%B0.xlsx)

1단계 프롬프트 · 온톨로지

해당 폴더의 엑셀 파일("피자 매장별 실적 데이터.xlsx")의 모든 시트를 읽고 온톨로지를 설계해서 html로 저장해줘.

2단계 프롬프트 · 지식 그래프

앞서 만든 온톨로지 html에 엑셀 파일의 실제 대상들을 연결한 지식 그래프를 추가해줘. 그리고 아래 질문 3개에 그래프를 따라가며 답해줘. 1. 배민 수수료 인상은 어느 매장의 어느 달 이익률에 영향을 줬나? 2. 밀크팜 치즈 단가 인상은 어떤 메뉴와 매장에 영향을 주나? 3. 2026년 4월 홍대점 클레임 폭증은 어떤 사건들과 이어져 있나?

 [ 완성 샘플 보기](https://bizroasting.com/assets/claudecode/06_ontology/ontology.html) [ 온톨로지와 지식 그래프 설명 보기 ](https://bizroasting.com/company-brain.html#wiki)

1단계 · 채팅에서 먼저

마인크래프트처럼 네모난 블록으로 된 3D 게임을 브라우저에서 만들려고 해. 해 질 녘 사원 정원에서 장화 신은 고양이를 3인칭으로 조종해 영혼의 구슬 7개를 모으는 게임이야. 아래 내용을 담은 PLAN.md를 작성해줘. - 화면: 노을 하늘, 블록 픽셀 질감, 빛 번짐, 반딧불과 벚꽃잎 - 조작: WASD·방향키 이동, 마우스 시점, Shift 질주, Space 점프 - 게임: 타이틀 화면, 나침반·타이머, 일시정지, 다 모으면 불꽃놀이 축하 장면 - 기술 스택(React, Three.js, Vite), 파일 구조, 구현 순서
