 구조 & 레이아웃 10

 필수 히어로 Hero Section ★★★

💡 랜딩 페이지 맨 위의 대형 배너 영역

예: 쿠팡 첫 화면 대형 배너, 네이버 메인 뉴스 영역

랜딩 페이지첫 화면

 💬 히어로 섹션 만들어줘. 제목, 부제목, CTA 버튼 포함하고 배경은 그라데이션으로 해줘 복사

 필수 카드 Card ★★★

💡 관련 정보를 한 박스에 모은 만능 컨테이너

예: 쿠팡 상품 목록, 인스타그램 피드 게시물

상품 목록블로그 포스트

 💬 카드 컴포넌트 만들어줘. 이미지, 제목, 설명, 가격, 버튼 포함 복사

 필수 그리드 Grid ★★★

💡 카드나 이미지를 가지런히 배열하는 격자판

예: 넷플릭스 영화 목록, 핀터레스트 이미지 갤러리

갤러리대시보드

 💬 3열 반응형 그리드 레이아웃 만들어줘. 모바일에서는 1열로 복사

 컨테이너 Container ★★★

💡 콘텐츠 폭을 제한해서 가운데로 모아주는 틀

예: 모든 웹사이트의 중앙 정렬 영역

페이지 래퍼max-width

 💬 최대 너비 1200px 컨테이너 레이아웃 만들어줘 복사

 사이드바 Sidebar ★★★

💡 화면 왼쪽이나 오른쪽에 붙는 세로 메뉴 패널

예: Gmail 왼쪽 메뉴, 유튜브 사이드 메뉴

관리자 패널필터

 💬 왼쪽 사이드바 + 오른쪽 메인 콘텐츠 레이아웃 만들어줘 복사

 디바이더 Divider ★★★

💡 콘텐츠 사이를 구분하는 가로 줄

예: 설정 페이지의 섹션 구분선

섹션 구분리스트 구분

 💬 섹션 사이에 디바이더 넣어줘 복사

 벤토 그리드 Bento Grid ★★★

💡 크기가 다른 칸을 도시락처럼 채운 격자

예: Apple 제품 페이지의 기능 요약, SaaS 랜딩 페이지 기능 소개

기능 소개랜딩 페이지

 💬 벤토 그리드로 기능 소개 섹션 만들어줘. 큰 칸 1개 + 작은 칸 4개 복사

 가격표 Pricing Table ★★★

💡 요금제를 나란히 놓고 비교하게 하는 표

예: ChatGPT·Notion 요금제 선택 화면

SaaS구독 요금제

 💬 가격표 만들어줘. 3개 플랜 + 추천 배지 + 월간/연간 토글 복사

 분할 화면 Split Layout ★★★

💡 화면을 좌우로 나눠 이미지와 글을 나란히 둔 배치

예: 로그인 화면 왼쪽 일러스트, 서비스 소개의 이미지+설명 블록

로그인 화면소개 블록

 💬 좌우 분할 레이아웃 만들어줘. 왼쪽 이미지, 오른쪽 글과 버튼 복사

 필수 푸터 Footer ★★★

💡 페이지 맨 아래 저작권·연락처 자리

예: 모든 웹사이트 하단의 저작권·링크 영역

하단 정보저작권

 💬 푸터 만들어줘. 로고, 링크 3열, 저작권 표시, SNS 아이콘 포함 복사

 이동 & 내비게이션 10

 필수 내비게이션 바 Navbar ★★★

💡 사이트 상단에 항상 따라오는 메뉴 막대

예: 네이버 상단 메뉴, 쿠팡 카테고리 바

글로벌 메뉴고정 헤더

 💬 상단 고정 내비게이션 바 만들어줘. 로고, 메뉴 4개, 로그인 버튼 복사

 필수 탭 Tab ★★★

💡 같은 자리에서 화면만 전환하는 수평 메뉴

예: 쿠팡 상품 상세/리뷰/문의 탭

설정 페이지카테고리 전환

 💬 탭 메뉴 3개 만들어줘. 클릭하면 콘텐츠 전환되게 복사

 검색 바 Search Bar ★★★

💡 키워드를 입력해서 원하는 것을 찾는 입력창

예: 구글 검색창, 네이버 검색 바

헤더 검색필터

 💬 돋보기 아이콘 있는 검색 바 만들어줘 복사

 메뉴 Menu ★★★

💡 클릭하면 아래로 펼쳐지는 선택 목록

예: 카카오톡 더보기(⋯) 메뉴

더보기컨텍스트 메뉴

 💬 더보기 클릭하면 드롭다운 메뉴 나오게 해줘 복사

 브레드크럼 Breadcrumb ★★★

💡 "홈 > 카테고리 > 현재 페이지" 경로 표시

예: 쿠팡 상품 페이지 상단 경로 표시

경로 표시뒤로 가기

 💬 브레드크럼 내비게이션 만들어줘. 홈 > 카테고리 > 상세 복사

 페이지네이션 Pagination ★★★

💡 1 2 3 ··· 다음 형태의 쪽 번호

예: 네이버 검색 결과 하단 페이지 번호

검색 결과게시판

 💬 페이지네이션 만들어줘. 이전/다음 + 숫자 버튼 복사

 드로어 Drawer ★★★

💡 옆에서 스르륵 밀려 나오는 슬라이드 패널

예: 모바일 햄버거(☰) 메뉴 클릭 시 패널

모바일 메뉴상세 보기

 💬 왼쪽에서 밀려 나오는 드로어 메뉴 만들어줘 복사

 스텝퍼 Stepper ★★★

💡 ① → ② → ③ 형태의 단계 진행 표시

예: 쿠팡 결제 과정 (장바구니→주문→결제→완료)

회원가입결제 과정

 💬 3단계 스텝퍼 만들어줘. 현재 단계 강조, 완료는 체크 복사

 커맨드 팔레트 Command Palette ★★★

💡 단축키 한 번으로 여는 검색창 겸 명령 실행기

예: Notion·Slack의 Cmd+K 빠른 이동, VS Code 명령 팔레트

단축키빠른 이동

 💬 Cmd+K 커맨드 팔레트 만들어줘. 실시간 검색 + 방향키 선택 복사

 하단 탭 바 Bottom Navigation ★★★

💡 모바일 화면 맨 아래에 고정된 아이콘 메뉴

예: 카카오톡·인스타그램 하단 메뉴

모바일 앱하단 고정

 💬 모바일 하단 탭 바 만들어줘. 아이콘 4개 + 현재 탭 강조 복사

 입력 & 폼 요소 11

 필수 버튼 Button ★★★

💡 클릭하면 뭔가가 실행되는 UI 기본 부품

예: 모든 웹사이트의 "확인", "구매하기" 버튼

CTA제출취소

 💬 버튼 세트 만들어줘. Primary, Secondary, Danger 3종류 복사

 FAB Floating Action Button ★★★

💡 화면 구석에 떠 있는 둥근 액션 버튼

예: Gmail의 ✏️ 새 메일 쓰기 버튼

새 글 쓰기빠른 추가

 💬 오른쪽 하단 플로팅 액션 버튼(FAB) 만들어줘 복사

 필수 인풋 Input / Text Field ★★★

💡 한 줄짜리 텍스트 입력 칸

예: 로그인 화면의 아이디/비밀번호 입력칸

검색창로그인 폼

 💬 인풋 필드 만들어줘. 라벨, 플레이스홀더, 에러 상태 포함 복사

 텍스트에어리어 Textarea ★★★

💡 여러 줄 입력 가능한 넓은 텍스트 칸

예: 배달의민족 리뷰 작성 칸

댓글문의 폼

 💬 텍스트에어리어 만들어줘. 글자 수 카운터 포함 복사

 셀렉트 Select / Dropdown ★★★

💡 클릭하면 목록이 펼쳐지는 선택 상자

예: 회원가입 시 생년월일 선택

국가 선택정렬 기준

 💬 셀렉트 드롭다운 만들어줘. 기본값 '선택하세요' 복사

 체크박스 Checkbox ★★★

💡 여러 개를 동시에 고를 수 있는 네모 칸

예: 이용약관 "모두 동의" 체크 박스

약관 동의필터

 💬 체크박스 그룹 만들어줘. '전체 선택' 포함 복사

 라디오 Radio Button ★★★

💡 여러 개 중 딱 하나만 고르는 동그라미

예: 쿠팡 결제 시 카드/계좌이체 선택

결제 수단배송 옵션

 💬 라디오 버튼 그룹 만들어줘. 옵션 3개, 단일 선택 복사

 토글 Toggle / Switch ★★★

💡 켜기/끄기를 전환하는 스위치

예: 아이폰 설정의 켜기/끄기 스위치

설정다크 모드

 💬 토글 스위치 만들어줘. ON/OFF 색 전환 복사

 필수 폼 Form ★★★

💡 여러 입력 요소를 묶어 한 번에 제출하는 양식

예: 네이버 회원가입 양식, 주문서 작성 페이지

회원가입주문서

 💬 회원가입 폼 만들어줘. 이름, 이메일, 비밀번호 + 유효성 검사 복사

 슬라이더 Slider / Range ★★★

💡 막대를 좌우로 밀어 값을 조절하는 조절기

예: 유튜브 음량 조절 바

가격 필터설정 조절

 💬 가격 범위 슬라이더 만들어줘. 최소~최대 설정 복사

 칩 Chip ★★★

💡 작은 알약 모양의 선택·필터 요소

예: 배달앱 "한식/중식/일식" 필터 칩

태그 필터선택 표시

 💬 필터 칩 그룹 만들어줘. 선택 시 색 변경 + X 삭제 복사

 피드백 & 알림·상태 10

 필수 모달 Modal / Dialog ★★★

💡 화면 위에 뜨는 팝업 대화 상자

예: "정말 삭제하시겠습니까?" 확인 팝업

삭제 확인로그인

 💬 모달 만들어줘. 제목, 내용, 확인/취소 + 배경 클릭 닫기 복사

 필수 토스트 Toast / Snackbar ★★★

💡 구석에 잠깐 나타났다 사라지는 알림

예: "장바구니에 추가되었습니다" 알림

저장 완료에러 알림

 💬 토스트 알림 만들어줘. 성공/에러/경고 + 3초 후 사라짐 복사

 얼럿 Alert / Banner ★★★

💡 페이지 안에 고정되는 정보/경고/에러 배너

예: "비밀번호가 틀렸습니다" 빨간 경고 박스

시스템 공지유효성 에러

 💬 얼럿 배너 4종류 만들어줘. 정보/성공/경고/에러 복사

 프로그레스 바 Progress Bar ★★★

💡 작업 진행률을 보여주는 가로 막대

예: 파일 업로드 진행률 표시

업로드학습 진행률

 💬 프로그레스 바 만들어줘. 퍼센트 + 애니메이션 복사

 스피너 Spinner / Loader ★★★

💡 빙글빙글 도는 로딩 표시

예: 인스타그램 피드 로딩 시 회전 아이콘

데이터 로딩버튼 대기

 💬 로딩 스피너 만들어줘. 원형 회전 애니메이션 복사

 스켈레톤 Skeleton ★★★

💡 콘텐츠 자리를 회색으로 미리 잡아두는 로딩

예: 유튜브 영상 로딩 시 회색 뼈대

피드 로딩카드 로딩

 💬 스켈레톤 로딩 만들어줘. shimmer 효과 포함 복사

 빈 상태 Empty State ★★★

💡 보여줄 데이터가 없을 때 대신 띄우는 안내 화면

예: 비어 있는 장바구니 화면, 검색 결과 없음

결과 없음첫 사용

 💬 빈 상태 화면 만들어줘. 일러스트 + 안내 문구 + 추가 버튼 복사

 알림 센터 Notification Center ★★★

💡 종 아이콘을 누르면 펼쳐지는 알림 목록

예: 유튜브·페이스북 상단 종 아이콘

읽지 않음 표시드롭다운

 💬 종 아이콘 알림 센터 만들어줘. 개수 배지 + 알림 목록 복사

 온보딩 투어 Product Tour ★★★

💡 처음 온 사용자에게 화면 요소를 하나씩 짚어 주는 안내

예: 새 앱 첫 실행 때 뜨는 '여기를 눌러 보세요' 말풍선

첫 사용기능 안내

 💬 온보딩 투어 만들어줘. 주요 버튼 3개를 차례로 강조 + 말풍선 복사

 바텀 시트 Bottom Sheet ★★★

💡 화면 아래에서 올라오는 슬라이드 패널

예: 카카오맵 장소 상세정보 패널

모바일 필터공유 메뉴

 💬 바텀 시트 만들어줘. 아래에서 올라오고 드래그 조절 복사

 표시 & 데이터 9

 필수 테이블 Table ★★★

💡 행과 열로 데이터를 정리하는 표

예: 쿠팡 주문 내역, 엑셀처럼 보이는 데이터 표

주문 내역데이터 목록

 💬 데이터 테이블 만들어줘. 정렬, 줄무늬 배경, 호버 효과 복사

 리스트 List ★★★

💡 항목을 세로로 쭉 나열하는 목록

예: 카카오톡 채팅 목록, 메일함 목록

설정 메뉴연락처

 💬 리스트 만들어줘. 아이콘, 제목, 부제목, 화살표 복사
