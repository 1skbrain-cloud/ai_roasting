루틴이란

## 정해진 시각에, 사람 없이 알아서 도는 에이전트입니다

Routines는 일정에 맞춰 무인으로 실행되는 예약 에이전트입니다. "매일 아침 9시에 어젯밤 뉴스를 정리해 줘"처럼 시각과 할 일을 한 번 등록해 두면, 그 시각이 될 때마다 Claude가 알아서 그 일을 처리합니다. 프롬프트, 저장소 접근, 연결한 도구를 한 번 묶어 두면 그다음부터는 스스로 돕니다.

#### 정해진 일정

매시·매일·평일·매주 또는 특정 시각에 자동으로 시작합니다.

매주 월요일 08:00

#### 클라우드 실행

Anthropic 클라우드에서 돌릴 수 있어, 기기를 켜 둘 필요가 없습니다.

노트북이 꺼져 있어도 실행

#### 무인 자동

사람이 매번 시작 버튼을 누르지 않아도 알아서 돌고 결과를 남깁니다.

결과는 정해둔 곳으로 전달

한 번 예약하면 내가 자는 동안에도 일이 끝나 있습니다.

 반복 작업을 사람의 손에서 완전히 떼어 내는 단계입니다.

언제 생겼나

Routines는 2026년 4월 14일 클로드 코드에 리서치 프리뷰로 처음 공개됐습니다. 유료 플랜(Pro·Max·Team·Enterprise)에서 쓸 수 있습니다.

로컬과 원격

## 내 컴퓨터에서 돌릴지, 클라우드에서 돌릴지 고릅니다

루틴을 만들 때 실행 장소를 로컬과 원격 중에서 정합니다. 둘의 차이는 "내 기기가 켜져 있어야 하는가"입니다.

#### 로컬 · 내 컴퓨터

내 기기에서 직접

- 클로드 코드를 켜 둔 내 컴퓨터에서 실행

- 기기가 켜져 있고 세션이 떠 있어야 함

- 내 환경·파일을 그대로 쓰며 직접 지켜볼 때

#### 원격 · 클라우드

Anthropic 클라우드에서

- 내 노트북이 꺼져 있어도 실행

- 트리거되면 클라우드가 컨테이너를 띄워 끝까지 처리

- 결과는 산출물로 남기거나 웹훅으로 전달

고르는 기준

내 컴퓨터의 로컬 환경이나 켜 둔 세션이 꼭 필요하면 로컬, 항상 켜둘 서버나 직접 만든 크론 없이 알아서 돌게 하려면 원격입니다. 무인 자동화의 진가는 원격에서 나옵니다.

만드는 법

## 저장소·환경·트리거·작업, 네 칸을 채웁니다

루틴을 만드는 화면은 네 칸으로 돼 있습니다. 어디서(저장소), 어떤 작업대에서(환경), 언제(트리거), 무엇을(작업) 할지를 정합니다. 코드를 다루지 않는 작업이면 저장소와 환경은 기본값 그대로 둬도 됩니다.

 1

#### 저장소

루틴이 다룰 코드가 있는 곳입니다. 깃허브 저장소를 하나 고릅니다. 깃허브 이벤트로 켜려면 먼저 골라야 합니다. 코드 작업이 아니면 비워 둬도 됩니다.

 2

#### 환경

루틴이 돌아갈 클라우드 작업대입니다. 어떤 도구·런타임·비밀값이 깔려 있는지를 묶은 설정입니다. 손볼 게 없으면 Default 그대로 둡니다.

 3

#### 트리거

루틴을 언제 켤지 정합니다. 일정·API 호출·깃허브 이벤트 가운데 고릅니다. 한 루틴에 여러 트리거를 함께 붙일 수도 있습니다.

 4

#### 작업

켜졌을 때 할 일입니다. "어젯밤 뉴스를 5건으로 정리해 메일로 보내 줘"처럼 평소 클로드에게 시키듯 적습니다.

트리거 세 가지를 좀 더 보면 이렇습니다.

#### 스케줄

반복되는 cron 일정으로 돌리거나, 미래의 특정 시각에 한 번만 돌립니다.

매일 09:00 · 매주 월 08:00

#### API 호출

전용 주소로 외부에서 HTTP 요청을 보내면 그때 한 번 실행됩니다.

다른 시스템이 필요할 때 호출

#### GitHub 이벤트

저장소에 PR·푸시·릴리스 같은 일이 생기면 자동으로 실행됩니다.

PR 열릴 때 자동 점검

관리하기

## 예약을 보고, 고치고, 멈춥니다

한 번 만든 루틴은 목록으로 확인하고 언제든 수정하거나 멈출 수 있습니다. 무인으로 돌기 때문에 처음 설계할 때 안전장치를 함께 거는 것이 중요합니다.

#### 이렇게 관리합니다

- 예약 목록 보기 · 다음 실행 시각 확인

- 일정·작업 내용 수정

- 잠시 끄기 또는 완전히 삭제

- 지금 한 번 바로 실행해 결과 점검

#### 안전하게 거는 법

- 되돌릴 수 없는 동작은 자동 실행 금지

- 발송·결제·삭제는 초안까지만, 승인은 사람이

- 결과를 받아 볼 곳을 분명히 지정

- 처음엔 1회성으로 시험한 뒤 반복으로 전환

루프 엔지니어링(/loop)과 무엇이 다릅니까?

[루프](https://bizroasting.com/loop-engineering.html)는 지금 열어 둔 세션 안에서 도는 반복이라 세션을 닫으면 멈춥니다. Routines는 일정에 맞춰 예약해 두는 것이라, 원격으로 걸면 내가 접속해 있지 않아도 정해진 시각에 무인으로 실행됩니다.

결과는 어디서 봅니까?

예약을 만들 때 받아 볼 곳을 지정합니다. 메일로 보내거나, 파일로 남기거나, 메신저로 알리도록 작업에 적어 두면 그곳으로 결과가 전달됩니다.

메일 발송이나 결제까지 자동으로 시켜도 됩니까?

권하지 않습니다. 무인으로 도는 만큼, 되돌리기 어려운 동작은 초안까지만 맡기고 발송·결제·삭제 같은 최종 실행은 사람 승인을 사이에 두는 것이 원칙입니다.
